# 전략 점검 — 2026-10-08

공개 BTCUSDT 선물 15분 봉 17,279개와 펀딩 이력 539건으로 기존 전략과 여섯 대안을 비교했다. 비교에서 교체할 만한 수익성 있는 후보를 찾지 못했다. 현재 진입 지표는 유지하고 보호 주문의 범위를 직접 설정할 수 있도록 변경했다. 이 비교는 사용자의 실제 계정 거래 성적이 아니다. 현재 브라우저 연결 오류 때문에 실제 계정의 청산 내역은 이번 작업에서 읽지 못했다.

## 손절과 익절이 넓은 이유

기존 손절 거리 = max(1.5 × ATR14, 최근 10봉 저점/고점까지 거리 + 0.2 × ATR, 가격 × 0.35%). 최근 10봉은 2시간 30분이다. 손절 거리가 가격의 1.5%를 넘으면 진입하지 않고, 익절은 손절 거리의 2배이다. 따라서 허용 손절은 0.35~1.5%, 익절은 0.7~3%이다. 10배 포지션의 증거금 대비 대략 -3.5~-15% / +7~+30%이며 실제 비용과 청산 위험은 별도다.

2:1 목표 손익비의 비용 전 손익분기 승률은 33.3%다. 비용을 반영하면 더 높다. 폭을 줄이면 왕복 수수료와 슬리피지가 손절 거리에서 차지하는 비율이 커진다. 예를 들어 손절 0.35%, 익절 배율 1.5, 왕복 비용 0.14%이면 단순 손익분기 승률은 약 56%다. 높은 승률이 높은 순수익을 뜻하지 않는다.

EMA·MACD·DI는 방향성 정보가 겹쳐 가산되며, 기존 점수는 횡보장 진입도 허용한다. 이것은 개선 가설이지 실제 계정 손실의 원인을 확정한 것은 아니다. 대안은 비용 반영 검증에서 실패하여 적용하지 않았다.

## 실행 및 한계

`npm run research` — 고정된 공개 데이터 기간을 다운로드하고 `.local/research/comparison.json`에 결과 저장. 재실행은 캐시를 사용한다. API 키 없이 공개 조회만 한다. 데이터 원문 해시(SHA256): `2464dc11f8bea90f63b09f9dad88fcca00808b4f2617c8e228ed600d14ea3f28`.

닫힌 봉 신호 다음 봉의 시가에 진입하고 같은 봉 손절·익절 충돌은 손절 우선으로 가정한다. 청산 후 같은 봉 재진입 금지, UTC 일별 3% 손실 / 3연속 손실 제한을 반영했다. 봉 종가 기반 낙폭 추정은 봉 내부 최대 낙폭을 측정하지 않는다. 가격 봉은 거래 가격이며 실제 보호 주문은 MARK_PRICE 기준이다. 주문 단위 반올림, 호가·지연, 청산, Demo 특유의 체결은 모델링하지 않았다. 사용자 지정 배수·증거금·실제 수수료 등과도 다를 수 있다.

## 배포 변경

- 손절 최대폭 0.35~1.5%, 익절 배율 0.5~3을 Demo/실계정별 영구 저장.
- 저장된 최대폭을 넘는 신규 진입은 생략. 손절을 억지로 가까이 옮기지 않음.
- 기본값은 기존 1.5% / 2배를 유지. 계정의 배수·증거금 및 기존 포지션·보호 주문은 변경하지 않음.
- 평탄한 가격의 RSI를 0에서 중립값 50으로 수정.
- 모바일 대응 계산 근거 및 탐색 결과 표시.
- 실제 자금 거래 허용 설정은 여전히 별도로 제한됨.
